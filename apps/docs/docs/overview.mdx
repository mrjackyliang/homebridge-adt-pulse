## What Is This?

ADT Pulse for Homebridge is a [verified Homebridge plugin](https://github.com/homebridge/homebridge/wiki/verified-Plugins#verified-plugins) for ADT Pulse customers. It lets homeowners control their security system and view <Terminology title="A portal device you list in config so it shows up in Home" to="/docs/reference/terminology#plugin-configuration">sensor</Terminology> status through the Home app.

The plugin talks to the <Terminology title="The ADT website the plugin talks to for everything" to="/docs/reference/terminology#adt-pulse-and-homebridge">ADT Pulse Web Portal</Terminology>, which is powered by Icontrol One and owned by ICN Acquisition LLC, an indirect subsidiary of [Alarm.com](https://alarm.com).

## Getting Started

Setting up the plugin takes three simple steps:

1. Run `npm install homebridge-adt-pulse`.
2. Configure the plugin using the sample provided in the [Configuration](/docs/getting-started/configuration/) guide.
3. Restart Homebridge and see the magic happen.

Another option is to search for `adt-pulse` using oznu's [Homebridge Config UI](https://github.com/oznu/homebridge-config-ui-x). Afterward, you can configure the plugin through the <Terminology title="The web page where you install and set up Homebridge plugins" to="/docs/reference/terminology#adt-pulse-and-homebridge">configuration UI</Terminology> available in the "Plugins" tab.

See the [Installation](/docs/getting-started/installation/) guide for the full walkthrough.

## Default Accessories

The plugin exposes these devices by default:

| Accessory                                                                                                                                              | Type          |
|--------------------------------------------------------------------------------------------------------------------------------------------------------|---------------|
| <Terminology title="The ADT Pulse gateway, shown in Home by default" to="/docs/reference/terminology#accessories-and-arming">Gateway</Terminology>     | `gateway`     |
| <Terminology title="The Home tile you use to arm and disarm" to="/docs/reference/terminology#accessories-and-arming">Security Panel</Terminology>      | `panel`       |
| <Terminology title="Turn it off to silence a ringing alarm" to="/docs/reference/terminology#accessories-and-arming">Alarm Ringing Switch</Terminology> | `panelSwitch` |

## Configurable Sensors

The plugin can expose these <Terminology title="A portal device you list in config so it shows up in Home" to="/docs/reference/terminology#plugin-configuration">sensors</Terminology> in read-only mode, based on your configuration:

| Sensor Type   | Description                                          |
|---------------|------------------------------------------------------|
| `co`          | Carbon Monoxide Detector                             |
| `doorWindow`  | Door/Window Sensor :: Door Sensor :: Window Sensor   |
| `fire`        | Fire (Smoke/Heat) Detector                           |
| `flood`       | Water/Flood Sensor                                   |
| `glass`       | Glass Break Detector                                 |
| `heat`        | Heat (Rate-of-Rise) Detector                         |
| `motion`      | Motion Sensor :: Motion Sensor (Notable Events Only) |
| `shock`       | Shock Sensor                                         |
| `temperature` | Temperature Sensor                                   |

For the complete breakdown of default and configurable accessories, see [Supported Devices](/docs/getting-started/supported-devices/).

:::info
While named "ADT Pulse for Homebridge," this plugin accommodates only the accessories listed above. It does not serve as a comprehensive substitute for the [official ADT Pulse app](https://www.adt.com/help/faq/adt-pulse/adt-pulse-mobile-app).
:::

## Z-Wave Accessories

Z-Wave accessories connected to the ADT Pulse <Terminology title="The ADT Pulse gateway, shown in Home by default" to="/docs/reference/terminology#accessories-and-arming">gateway</Terminology> are not supported, and support is not planned. This is due to implementation complexity and platform instability.

If you rely on Z-Wave accessories, consider one of these alternatives:

- Purchase the [Hubitat Hub](https://hubitat.com) for a seamless setup experience.
- Read about the [Home Assistant Z-Wave](https://www.home-assistant.io/integrations/zwave_js/) integration.
