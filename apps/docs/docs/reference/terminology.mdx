## ADT Pulse and Homebridge

| Term                     | Also known as                    | Definition                                                                                                                                                           |
|--------------------------|----------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **ADT Pulse**            | —                                | The ADT home security service this plugin integrates with.                                                                                                           |
| **portal**               | ADT Pulse Web Portal             | The ADT Pulse Web Portal (powered by Icontrol One), the plugin's only data source. The `subdomain` setting selects `portal` (United States) or `portal-ca` (Canada). |
| **Homebridge**           | —                                | The Node.js server that hosts this plugin (`^1.11.0` or `^2.0.0` per `engines`).                                                                                     |
| **HAP**                  | HomeKit Accessory Protocol       | The protocol the Home app speaks. Homebridge exposes this plugin's accessories over it.                                                                              |
| **HOOBS**                | Homebridge Out Of the Box System | A standalone Homebridge distribution with its own UI and bridge management. The plugin supports it with adjusted installation steps.                                 |
| **Homebridge Config UI** | `homebridge-config-ui-x`         | The third-party web interface for managing Homebridge plugins, accessories, and settings through a browser.                                                          |
| **verified plugin**      | —                                | The Homebridge program status confirming the project team reviewed a plugin against its best-practice requirements. This plugin holds verified status.               |

## Setup and Login

| Term                     | Also known as         | Definition                                                                                                                                                                           |
|--------------------------|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **setup wizard**         | —                     | The guided flow in Homebridge Config UI that logs into the portal, completes 2-factor verification, creates a fingerprint, registers a trusted device, and writes the plugin config. |
| **fingerprint**          | —                     | The base64 device fingerprint the portal requires for 2-factor logins. The setup wizard creates it and saves it in the plugin configuration.                                         |
| **MFA / trusted device** | 2-factor verification | The portal's 2-factor flow: request an SMS or email one-time passcode, validate it, and register a trusted device.                                                                   |

## Plugin Configuration

| Term                      | Also known as            | Definition                                                                                                                                                |
|---------------------------|--------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| **platform**              | `ADTPulse`               | The Homebridge plugin type this project registers, implemented by `ADTPulsePlatform`.                                                                     |
| **platform block**        | `"platform": "ADTPulse"` | The JSON object inside `config.json`'s `platforms` array that holds this plugin's settings.                                                               |
| **sensor**                | —                        | A portal device declared in config via `adtName`, `adtZone`, `adtType`, and an optional `name`. Zones 1 through 99 are supported.                         |
| **System tab**            | —                        | The "System" tab in the portal, listing the Name, Zone, and Device Type columns used to configure sensors.                                                |
| **condensed sensor type** | `adtType`                | One of the nine `adtType` slugs: `co`, `doorWindow`, `fire`, `flood`, `glass`, `heat`, `motion`, `shock`, `temperature`.                                  |
| **operational mode**      | `mode`                   | The `mode` setting: `normal`, `paused` (devices non-responsive), or `reset` (removes plugin accessories after an approximately 40-second warning window). |

## Accessories and Arming

| Term                     | Also known as | Definition                                                                                                                     |
|--------------------------|---------------|--------------------------------------------------------------------------------------------------------------------------------|
| **gateway**              | —             | The ADT Pulse gateway device, exposed by default alongside the security panel and Alarm Ringing switch.                        |
| **security panel**       | —             | The alarm panel accessory that supports Arm Away, Arm Stay, Arm Night, and Disarm.                                             |
| **Alarm Ringing switch** | `panelSwitch` | The accessory used to silence a ringing alarm while the system is in "Disarmed" mode.                                          |
| **force arm**            | —             | The plugin's automatic bypass of open or active sensors when arming, required because the HAP protocol cannot prompt the user. |

## Portal Sessions

| Term           | Also known as | Definition                                                                                                                                  |
|----------------|---------------|---------------------------------------------------------------------------------------------------------------------------------------------|
| **sync check** | —             | The periodic portal signal that reports whether device state changed. Dispatched on the platform's interval, scaled by the `speed` setting. |
| **keep-alive** | —             | The periodic portal signal that keeps the logged-in session from expiring.                                                                  |

## Troubleshooting and Maintenance

| Term                | Also known as              | Definition                                                                                                                                            |
|---------------------|----------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| **detect report**   | —                          | A redacted anomaly payload sent to the plugin author when unknown devices or statuses are parsed. Known identifying fields are removed automatically. |
| **stale accessory** | orphaned accessory         | A cached Homebridge accessory that no plugin claims on startup. Homebridge can remove it unless you retain it with the `-K` or `--keep-orphans` flag. |
| **test scripts**    | `hap-test-api`, `hap-repl` | The bundled commands for troubleshooting portal connectivity and inspecting live API responses.                                                       |
