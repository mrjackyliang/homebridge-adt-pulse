Acknowledge the contributors and supporters who helped build and improve this plugin.

## Support Development

If you find value in the ongoing development of this plugin and wish to express your appreciation, you have the option to become a supporter on [GitHub Sponsors](https://github.com/sponsors/mrjackyliang).

Sponsorship helps sustain the time spent maintaining, testing, and improving the plugin over time.
